# Shadow Ninja

An original 2D action platformer built in **Godot 4 (GDScript)** featuring shadow silhouette art, fluid ninja movement mechanics, challenging traps, dynamic enemies, and epic boss battles.

## Features

- **Fluid Movement**: Run, jump, double jump, dash, wall slide, and wall jump.
- **Combat**: Ranged shuriken throwing system against hostile samurai and ninja patrols.
- **12 Levels**: Progress through 12 increasingly challenging stages filled with spikes, moving saw blades, pits, and laser barriers.
- **Epic Boss Fights**: Face formidable bosses at levels 4, 8, and 12.
- **Collectibles & Checkpoints**: Gather stars/coins in every level and activate checkpoints to save your progress.
- **Cross-Platform Controls**: Full keyboard/mouse support on desktop and responsive on-screen touch controls for mobile devices.
- **Procedural Shadow Art & SFX**: Custom silhouette aesthetic paired with synthesized sound effects and atmospheric parallax backgrounds.

## Controls

| Action | Keyboard / Mouse | Touch Controls |
|---|---|---|
| **Move Left / Right** | `A` / `D` or Left / Right Arrows | Left / Right On-Screen Buttons |
| **Jump / Double Jump** | `Spacebar` | Jump Button |
| **Dash** | `J` | Dash Button |
| **Throw Shuriken** | `K` | Throw Button |
| **Pause** | `Escape` | Pause Menu |

## Built With

- **Engine**: [Godot 4](https://godotengine.org) (GDScript)
- **Art & Audio**: Python PIL & Wave synthesis
- **Build System**: GitHub Actions

## Installation & Running

1. Clone the repository and open the project folder in **Godot 4.3+**.
2. Run the project (`F5`) or export for Web / Desktop / Mobile.
